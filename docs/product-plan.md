## Context

LeadMaker resells white-label SEO from an Indian vendor (about $100 cost, $300 price per account). They want their own enterprise SEO/GEO platform so they can serve clients paying around $3,000 a month, with 1–2 back-office staff and VAs. Mark mocked up the idea as a Claude artifact (claude.ai/artifact/XdTReWgeKiQarJSPmiz7MQ, read in full: 1,173 lines) and explained it on video. Stefan started a cost-notes doc (Digital Ocean, Supabase, Ayrshare/Zernio, a custom WordPress API, DataForSEO).

The artifact only shows the idea, so the build can change the layout. Scope: the SEO platform only, based mainly on the artifact.

**Deliverable:** one shareable, editable doc in the same style as Stefan's notes. It opens with a plain-language summary for Mark, followed by a technical section for the build. The sections below are the doc's content. Execution means writing this into the doc.

## 3. Recommended architecture (the build)

- **Frontend + API:** Next.js (TypeScript) on DigitalOcean App Platform. Two hosts: `app.leadmaker.agency` (agency) and `connect.leadmaker.agency` (client onboarding, review pages, approvals).
- **Database/Auth/Storage:** Supabase (Postgres, Auth with the 5 roles enforced through row-level security, Storage for images and PDFs, Vault for client secrets).
- **Background worker:** a separate DO worker running a Postgres-backed job queue (pg-boss) for scheduled rank checks, grid scans, AI checks, audits, publishing, token-expiry checks, review-request sends and report generation.
- **Integrations behind interfaces:** `SocialProvider` (Zernio | Ayrshare: socials, GBP posting, review replies, profile stats), `SerpProvider` (DataForSEO), `LlmVisibilityProvider`, `CmsPublisher` (WP plugin | fallback: Zernio blog or application password | Webflow | Shopify | manual), `Messaging` (Postmark/Resend, Twilio).
- **AI:** Claude API. Use Sonnet 5.5 for articles, social variants and review replies ($2/$10 per M tokens), Opus 5.5 ($4/$20) for the audit and report summaries, and Haiku 5.5 for classification. Prompt caching covers the per-client brand and brief context.
- **WordPress plugin:** "LeadMaker Connector". The client uploads it once and clicks Connect; plugin and server exchange a secret key, and every request is signed (timestamp + HMAC, replays rejected). Acts as a dedicated LeadMaker admin user, exposes a fixed action list (posts/pages incl. Elementor/Divi, media, menus, Yoast/Rank Math SEO fields, JSON-LD schema, robots.txt rules, llms.txt, redirects, noindex, health check). Updates via our own update server; dashboard flags a deactivated plugin within a day.
- **Core tables:** clients, client_locations, keywords, rank_snapshots, grid_scans, ai_checks, audits/audit_items, directories (library), backlinks, articles, channel_posts, connections, vault_secrets, review_requests, reviews, tasks, task_clients, team_members, activity_log, reports.

## 4. Phased roadmap (rough sizing for one developer working with Claude Code)

- **Phase 0, week 1 (paperwork in parallel):** Google Cloud project and service account (GSC, GA4 read-only); DataForSEO $50 top-up; Zernio free tier (2 accounts) for the prototype; Ayrshare 28-day trial only when ready to compare; Anthropic API key; Postmark/Resend domain; Twilio 10DLC registration.
- **Phase 1, MVP (about 5–6 weeks):** agency shell (clients, team/roles, multi-client tasks, vault); onboarding wizard (Google, socials, WordPress, business details); Rankings (Google, Bing, map pack, weekly); content engine with WordPress plus social publishing; dashboard "Needs attention" from real events. Pilot with 2–3 real clients.
- **Phase 2 (about 4–5 weeks):** AI visibility audit plus automatic WP fixes; AI-answers tracking; geo-grid; directory library plus monthly backlink plan, VA flow and live-check; Reviews (requests, private feedback, AI replies).
- **Phase 3 (about 3–4 weeks):** full monthly report with PDF and email; Webflow/Shopify publishing; Gmail send-as-client; brand mentions; content calendar across clients.

## 5. Running costs (monthly, before staff)

Corrections to Stefan's notes: **Supabase "Small" needs the Pro plan** ($25 including $10 compute credit, so Small comes to about $30 total, not $15). Add **one worker** (about $5–12). **Ayrshare counts one "profile" per client** (each holding all of that client's networks), whereas **Zernio counts every network account** (about 6 per client: GBP, FB, IG, LinkedIn, Pinterest, WP).

| Item                                                              | 10 clients        | 50 clients                   | 100 clients       |
| ----------------------------------------------------------------- | ----------------- | ---------------------------- | ----------------- |
| Hosting (DO app + worker, Supabase Pro + Small)                   | ~$45              | ~$80                         | ~$150             |
| Social: Zernio (~6 accounts per client, graduated)                | ~$198             | ~$518                        | ~$818             |
| Social: Ayrshare alternative                                      | $299 (Launch, 10) | ~$760 (Business 30 + extras) | ~$1,150           |
| DataForSEO (ranks, maps, grid, AI answers, mentions)              | ~$50–150          | ~$250–750                    | ~$500–1,500       |
| Claude API (8 articles plus social posts, replies, audit, report) | ~$30              | ~$150                        | ~$300             |
| Email + SMS (Postmark/Resend + Twilio incl. 10DLC)                | ~$40              | ~$100                        | ~$200             |
| **Total (with Zernio)**                                           | **~$360–460**     | **~$1,100–1,600**            | **~$2,000–3,000** |
| **Per client**                                                    | ~$36–46           | ~$22–32                      | ~$20–30           |

Optional extras: BrightLocal citations (about $2–3 each), CallRail call tracking (per client), DataForSEO Backlinks API (check its monthly minimum), AI images (a few cents each). **The real cost is VA and manager time**, not software: at about $3,000 per client, tools are 1–2% of revenue.

Per-unit basis used: DataForSEO SERP/Maps from $0.0006 per request (standard queue); LLM Mentions about $0.10 per request plus $0.001 per row; LLM Responses about $0.0006 per task plus the model's own cost; Zernio $6/$3/$1 graduated per account; Ayrshare Launch $299/10 and Business $599/30. Mark every figure "verify on the vendor's pricing page before committing".

## 6. UX changes vs the mockup

Keep: the agency/client split, the Ctrl+K client switcher, multi-client tasks, the role matrix, the "3 places you show up" model, the status legend and the report structure. Change or add:

- The onboarding wizard and public review page (missing).
- Event-driven "Needs attention" (token expiring, publish failed, client hasn't connected, behind on deliverables).
- A cross-client content calendar.
- AI results shown as trends or ranges, with Copilot removed or marked "not tracked".
- A geo-grid run on demand instead of always.
- Directory library admin.
