# AI Visibility · 06 · Interface

The route is `src/app/(app)/clients/[clientSlug]/ai-visibility/page.tsx` (thin). The feature lives in `src/features/ai-visibility/`, with `queries.ts`, `actions.ts`, `config.ts`, `search-params.ts` and `components/`.

The design follows `docs/design-system.md`:

- one violet primary;
- status colours only through `StatusTag` and `StatusDot`;
- `tabular-nums` on numbers;
- tokens only;
- a real empty state on every list;
- shadcn components used as they are.

## 1. Page frame

```
PageHeader  eyebrow=client  title="AI visibility"  description=<last run · next run>  actions=[Run now] [Export]
SetupBar | SetupGate                    (same pattern as the backlinks setup bar)
FilterBar                               (date range · platforms · countries · tags AND/OR · topics)
Tabs (links, ?tab=)  Overview · Prompts · Chats · Brands · Sources · Actions · Settings
<tab body>
RunProgress (when a run is open; OverviewRefresher every 10s)
```

**Access and loading:**
- `AccessGuard` (nav item `ai-visibility`) and `Content` each sit in their own `<Suspense>`.
- `new Date()` is only used inside `Content`, and passed down as `nowIso`.

**Setup gate.** The tabs are locked, like the backlink tabs, until all of these hold:
1. a project with a brand name;
2. at least 1 platform;
3. at least 1 active question.

The gate card lists the missing steps from `aiv_quota.setup_missing`, with **Start setup**, which opens the Settings tab in setup mode.

**First-time setup** ("Set up AI visibility"):
1. **Profile:** brand name, description, industry and personas, prefilled by `seed_aiv_from_setup` from the client profile and backlink brief.
2. **Platforms and countries:** all 6 ticked; countries from the Backlinks places.
3. **Competitors:** from `client_competitors`, plus add or remove.
4. **Questions:** "Suggest questions" proposes about 25 across 4–6 topics (Haiku, about $0.005). Each can be accepted or edited, and you can add your own or paste many.
5. **Review:** the estimate ("about $1.60 a run, about $6.90 a month weekly"), then **Save and run the first check**.

**Phone width:** the filter bar collapses into a "Filters (3)" button that opens a sheet, and tabs scroll horizontally.

## 3. Tabs

### Overview

- **`StatStrip`** with 5 items: Visibility, Share of voice, Position, Sentiment and Win rate, for the own brand.
  - Each shows its value and a change arrow against the previous period. Arrows use the success or danger tone; Position is inverted.
  - The items aren't links (unlike the Backlinks strip), so the strip renders without `href`. If the component needs one, link to the matching sort in Brands.
- **Visibility trend** (`TrendChart`): the own brand plus up to 7 competitors by visibility, with a bucket switch (day, week, month) and a metric switch (visibility, SoV, position, sentiment, win rate). The legend sits above the chart, and lines are labelled directly when there are 4 or fewer.
- **Brands table:** rank, brand (colour dot and name), visibility, SoV, position, sentiment, win rate and change. The own brand is highlighted.
- **Top sources:** the top 10 domains (domain, type tag, retrieved %, cited %) and a source-type breakdown as a horizontal 100% bar with a legend. Links go to Sources.
- **Recent answers:** the last 10 chats (question, platform icon, the brands mentioned as chips in order, own brand in bold), each opening the chat sheet.
- **Empty:** "The first check is running. Results appear within about an hour", or, with no run yet, "Run the first check".

### Prompts

- **Table** (`@tanstack/react-table`) with columns: select, question, topic, tags, country, intent, branded, volume (1–5 dots), visibility, position, sentiment (own brand) and status.
- **Sorting and search:** sortable columns and a text search.
- **Toolbar:** **Add question** (one), **Paste questions** (one per line, up to 50), **Suggest questions**, and the Active/Archived toggle.
- **Batch bar:** add tag, remove tag, set topic, archive, reactivate, delete. Delete asks first and says that answers are deleted too.
- **Suggestions panel** (collapsible): "Ideas from Shockwave AI · N new", each with its reason and **Track** or **Dismiss**.
- **Question sheet:** text (editable), topic, tags, country, intent, persona, and the latest answer per platform (a chat card each), plus this question's visibility trend.
- **Cap note:** "38 of 50 questions active". Adding past 50 shows the RPC message.

### Chats

- **List:** paged, 25 per page. Each row shows date, question, platform, country, the brands mentioned (chips in order), whether the own brand is mentioned, and the number of sources.
- **Filters:** the shared bar, plus brand ("answers that mention …") and text search over questions.
- **Chat sheet** (`?sheet=<chat id>`):
  - **Header:** question, platform, country, model version, date, and "View on platform" (`check_url` when it exists, `rel="noopener noreferrer nofollow"`).
  - **Answer:** shown through `SafeAnswer` (below), with tracked brand names highlighted (own brand violet, competitors neutral underline).
  - **Brands mentioned:** a numbered list with position, sentiment (0–100 plus a short label) and quote.
  - **Sources:** two lists, **Cited** (in cite order) and **Read but not cited**. Each shows the favicon (letter fallback), title, domain and type tag.
  - **Follow-up searches the AI ran**, when there are fan-outs.
  - **Ads in this answer**, for ChatGPT.

**`SafeAnswer`** renders the untrusted answer without ever using `dangerouslySetInnerHTML` or any HTML from the answer.
- It splits the text into paragraphs and supports a small markdown subset: `#` headings become bold lines; `-`, `*` and `1.` lists; `**bold**`; and `[text](url)` links.
- Links show the text plus the domain and get `target="_blank" rel="nofollow noopener noreferrer"`.
- Images are not shown.
- Every other character is rendered as text.

### Brands

- **Tracked brands:** a list of cards. Each shows name, colour, aliases, pattern and domains, plus that brand's visibility and position.
- **Add brand** asks for display name, names to match (aliases), domains and an optional pattern. A **"Test"** box shows whether sample text matches.
- **Suggested brands:** "Named in N answers" with **Track** or **Reject**.
- **Brand insights** (`?brand=`):
  - the 5 KPIs and their changes;
  - strongest and weakest platform;
  - the trend chart for this brand with retrieved % of its domains overlaid;
  - top prompts where it wins or loses.
- **Performance matrix:** pick rows and columns from Platform, Brand, Topic, Tag and Country (at most 10 each) and a metric. It renders as a table with a sequential single-hue cell background (validated). The tooltip shows all metrics. A "Show numbers" toggle is on by default for accessibility.

### Sources

- **Domains and URLs** sub-views (segmented control):
  - **Domains:** domain, type, retrievals, retrieved %, cited %, citation share and avg cite rank, plus own and competitor markers.
  - **URLs:** URL and title, with the same metrics.
- **Type filter chips.**
- **Gap analysis** (the default sub-view when a gap exists), sorted by gap score. Each row has the domain and type, gap answers, a competitors avatar list, sample questions, and an action:
  - **Send to Backlinks** (`ai_visibility.work`), which becomes "In Backlinks · Review" once sent and links there;
  - **Create action**.
- A domain or URL row opens a **source sheet**: the questions that read or cite it, by platform, over time.

### Actions

- **Four group cards** with counts:
  - Fix how AI reads the site;
  - Improve your own pages;
  - Get mentioned elsewhere;
  - Fix wrong claims (shown as "Coming later" in this version).
- **List:** title, group, impact (`StatusTag`: high = brand, medium = info, low = neutral), status, domain, created date.
- **Filters:** status (New, In progress, Done, Declined) and group.
- **Action sheet:** "Why this matters" (the evidence: questions, platforms, competitors, answers), "What to do", and buttons Accept (In progress), Mark done, Decline, Restore. Earned actions also offer **Send to Backlinks**.
- **Add your own action:** group, title and detail.
- **Done** shows a toast: "Counts as an AI visibility fix this month."

### Settings

- **Setup:** project profile, platforms (6 toggles with a short note each, e.g. "ChatGPT as users see it" or "Claude through the API, with web search"), countries (1–3) and language.
- **Schedule:** frequency (weekly, twice a week and daily are admin-only and disabled for others, with a tooltip), weekday, paused, and next run.
- **Topics:** list editing.
- **Estimate card:** per run and per month for the current setup, plus this month's AI Visibility spend against the budget (admins see the budget value).
- **Admin-only budget controls:** `aiv_monthly_budget_usd`, `aiv_max_run_usd` and `aiv_manual_runs_per_client_month`, through a small `updateAiVisibilityBudget` action. The Rankings budget card only edits its own 3 fields.
- **Runs and costs:** the existing `RunHistoryPanel`, fed by `aiv_run_history`, with the new kind `ai_visibility` (icon `Radar`, label "AI visibility check"). Cost parts: DataForSEO and Claude.
- **Access notice:** when `aiv_access = 'denied'`: "AI Optimization isn't active on the DataForSEO account."

## 4. Charts (`src/features/ai-visibility/components/charts/`)

**Before writing any chart, load the dataviz skill and run `validate_palette.js`.**

- **`TrendChart`** generalises `rankings/components/position-chart.tsx`:
  - Hand-built SVG with a responsive width, 2px lines and ≥8px point markers.
  - A hover crosshair with a tooltip listing every series at that bucket.
  - Gaps for buckets with no answers, a "Show as table" toggle, and a single y-axis.
  - For position, the y-axis is inverted (1 at the top).
- **Colours:**
  - Categorical slots `--chart-1`…`--chart-8`. The 5 tokens in `src/app/globals.css` gain 3 more in light and dark, each validated (CVD ΔE ≥ 8, normal-vision floor ≥ 15, contrast against the card surface).
  - The colour comes from `aiv_brands.color_slot`, so a brand keeps its colour whatever the filter. The own brand is always slot 1 (violet).
- **Matrix heat:** one sequential hue, validated, with text in text tokens.
- **Source-type bar:** a categorical palette separate from the brand slots, with a 2px surface gap between segments and a legend with every segment labelled.

## 6. Export

An `exportAiVisibility(clientId, kind, filters)` server action, with kind one of `brands`, `prompts`, `sources`, `urls`, `chats` or `gap`. It returns a CSV string (RFC 4180, BOM for Excel), which the client downloads as `<client>-ai-visibility-<kind>-<date>.csv`. Limits are 10,000 rows, and answer text is excluded.

## 7. Permissions

| Permission (`src/lib/roles.ts` + `PERMISSION_LABELS`) | Roles | Covers |
|---|---|---|
| `ai_visibility.manage` | admin, manager | Setup, platforms, countries, questions, topics, brands, suggestions, Run now |
| `ai_visibility.work` | admin, manager, va | Actions (status, add), Send to Backlinks |
| `ai_visibility.frequency` | admin | Twice a week or daily, and the AI Visibility budgets |

- **Nav item:** `comingSoon: false`, roles `admin, manager, va, viewer`, and the summary text updated.
- **Viewers and VAs** see everything read-only, apart from the action controls VAs have.
- **The RPCs check the same permissions,** through `private.require_*` helpers that mirror `roles.ts`.
